🌙 Projeto Web — Meu Site
Um projeto web desenvolvido com HTML, CSS e JavaScript, criado no Visual Studio Code.

O projeto apresenta uma página inicial com botões interativos que direcionam para diferentes páginas, cada uma com seu próprio estilo visual.

✨ Funcionalidades
🎨 Interface moderna e estilizada

🖱️ Botões interativos com efeitos ao passar o mouse

✨ Animações e efeitos de brilho

📱 Design responsivo para computador e celular

🖼️ Página com espaço para foto de perfil

👤 Página "Sobre Mim"

⚔️ Página com estilo gótico medieval

🔗 Navegação entre diferentes páginas

📂 Estrutura
meu-projeto/
│
├── index.html
├── pagina1.html
├── pagina2.html

🏠 Página inicial
A página inicial possui dois botões coloridos e interativos.

Cada botão direciona o usuário para uma página diferente.

Os botões possuem:

Gradientes coloridos

Efeito de brilho

Animação ao passar o mouse

Efeito de escala ao clicar

👤 Página Sobre Mim
A página pagina2.html possui:

Foto de perfil circular

Área para informações pessoais

Design moderno

Fundo com gradientes

Efeito de vidro

Botão para voltar à página inicial

A imagem pode ser adicionada diretamente no código HTML através da propriedade src.

<img
    class="foto"
    src="LINK_DA_SUA_IMAGEM"
    alt="Minha foto">
